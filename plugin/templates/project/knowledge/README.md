The single-source-of-truth home for what {{project_name}} knows: research, domain
context, technical mechanics, synthesised from raw sources into canonical topic
docs. Each fact has exactly one home; raw originals stay verbatim in
[`archive/`](archive/).

## Conventions

- Frontmatter on every canonical doc: `title`, `status` (`draft` | `stable`),
  `last_updated`, `sources`.
- Every canonical doc ends with an **Open questions** section.
- `archive/` is append-only and verbatim.
