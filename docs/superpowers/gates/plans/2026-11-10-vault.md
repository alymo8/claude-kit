## Plan-introduced decisions

- `vault-pending.py` reports a third status, `missing`, for a source page whose raw file no longer exists (text line and JSON entry with `sha256` null); ingest lists these and leaves their pages unchanged (Task 2, Task 4)
- When a raw file changes, ingest removes from person and topic pages each fact linked to that source page that the new version no longer states, and lists each removal in the report (Task 4)
- A source page's `date` and file-name prefix are the date the material states, else the ingest date; task files are named `<source page date>-<slug>.md` (Task 4)
- The template ships a `.gitattributes` with `raw/** -text` so line-ending conversion never changes raw hashes (Task 1)
- vault-init rolls back only on a non-zero return from `git init`, `add` or `commit`, or an `OSError` from any git call: it deletes the whole destination if it created it, or every child (`.git` included) of a pre-existing empty one, and exits 1; a non-zero `git config --get` probe is the normal path into the `claude-kit <claude-kit@localhost>` identity fallback (Task 1)
- Task `owner` and `topic` are quoted wiki-links; `topic` falls back to the first of the call's `topics`, else empty (Task 4)
- With no matching task, task-prompt says so, lists the open tasks (status not `done`) and stops (Task 4)
- README and `tests/test_docs.py` say "twelve hooks", not the spec's "eleven": #52 already brought `origin/main` to 11 hook commands; the number is counted from `hooks.json` after Task 3 (Task 5)
- No README hook-list item is added for #52's PreCompact hook; the gap is mentioned in the PR (Task 5)
- The in-session hook observation for criterion 5 is deferred until after merge; before merge the hook script is run directly (Task 6)
- In the criterion 6 grep, a hit on an ordinary word that is not a reference to a repo is reviewed and recorded in the PR rather than counted as a failure (Task 6)
