## Plan-introduced decisions

- `vault-pending.py` reports a third status, `missing`, for a source page whose raw file is gone (JSON `source` = that page); ingest lists these and leaves their pages unchanged (Task 2, Task 4)
- The `raw/` walk is recursive and skips any path with a component starting with `.`; when two source pages name the same raw file, the first by sorted page name wins (Task 2)
- Task files are named `<call date>-<slug>.md` (source page `date`, ingest date only when the call states none); `topic` is the action item's own topic, else the first of the call's `topics`, else empty (Task 4)
- Without a configured git identity, the scaffold commit uses `-c user.name=claude-kit -c user.email=claude-kit@localhost` and never writes git config (Task 1)
- `person.md` and `topic.md` gain an `aliases: []` frontmatter key, which ingest searches besides the page name (Task 1, Task 4)
- Wiki-links in frontmatter are quoted, and `vault-pending.py` strips one pair of surrounding quotes (Task 1, Task 2, Task 4)
- The hook uses profile `unknown` when `vault.toml` has no `profile` key (Task 3)
- Criterion 5's in-session observation is done once after merge (the installed kit lacks the hook until then); before merge only the hook run from the CLI is checked (Task 6)
