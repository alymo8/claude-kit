# Publish the kit as a Claude Code plugin (agent-kit) Implementation Plan

- **Status:** approved
- **Date:** 2026-11-23
- **Frozen:** none (the spec has no Frozen bullet; spec D10: nothing is frozen)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `plugin/` a self-contained Claude Code plugin named `agent-kit`, installable from a marketplace hosted in this repo, while `install.py` keeps working for contributors, Vibe, Codex and Cursor.

**Architecture:** `conventions/` and the workspace rules move under `plugin/` (`plugin/conventions/`, `plugin/rules.md`); the root `AGENTS.md` imports the rules. The kit-map and workspace-rules hooks read from the folder next to them, so they work from Claude Code's plugin cache. A root `.claude-plugin/marketplace.json` lists `./plugin`. Every `claude-kit` name becomes `agent-kit`, except the state paths, env vars and legacy constants the spec keeps. `install.py` migrates old links, status lines and agent blocks; a new `/agent-kit:statusline` command writes a status line that survives plugin updates.

**Tech Stack:** Python 3.11 standard library (installer parseable by 3.8), pytest, ruff, Markdown, JSON, Claude Code CLI (`claude plugin validate`, `claude plugin marketplace add`, `claude plugin install`).

**Spec:** `docs/superpowers/specs/2026-11-23-publish-plugin-design.md`

Spec gate record: `docs/superpowers/gates/2026-11-23-publish-plugin-design.md`

  Python 3.8 up to its version check (no `Path.is_relative_to`,
  `str.removeprefix`, `match`).
- Hooks always exit 0 and print errors to stderr with a `[agent-kit]`
  prefix (after Task 4; `[claude-kit]` until then).

  `--skills-dir` and `--home`; every test removes the links it creates.
- Keep unchanged (spec D5): every `CLAUDE_KIT_*` variable, `~/.claude/claude-kit/`,
  the context-nudge paths `<scratch>/claude-kit/nudge-level` and
  `claude-kit-nudge-<session>`, the Docker label `claude-kit.task`, and the
  repo URL `alymo8/claude-kit`.
- GitHub URL base for history links: `https://github.com/alymo8/claude-kit/blob/main/<path>`.
- Plugin version `1.0.0`; plugin and marketplace name `agent-kit`;
  `owner.name` and `author.name` `alymo8`.
- Never edit `docs/superpowers/` history, `docs/audit/`, `vendor/`, or the
  bodies of `knowledge/decisions/0*.md` (only the status lines of the five
  amended ADRs change).
- This repo is public: no machine username, no private repo name, no
  absolute home path in any tracked file (use `<worktree>`, `%USERPROFILE%`).

## Review Focus

- `installed_plugins.json` missing, malformed, or with a non-list entry →
  `install.py` links as if no marketplace copy existed and never raises
  (Task 3 test `test_malformed_installed_plugins_links_normally`).
- An old status line written with Windows backslashes or different case
  (`python "C:\...\Skills\claude-kit\scripts\statusline.py"`) → still
  recognised and migrated (Task 3 test `test_legacy_statusline_with_backslashes_migrates`).
- A plugin installed under a path with spaces → the stable status line is
  quoted and runs (Task 3 test `test_stable_line_survives_cache_version_change`
  uses a cache folder with a space).
- A folder whose `.claude-plugin/marketplace.json` is malformed, not an
  object, or names another marketplace → not a kit checkout; the hook still
  exits 0 and injects (Task 2 test `test_malformed_or_foreign_marketplace_is_not_a_kit`).
- An agent file holding both an old `claude-kit` block and a new
  `agent-kit` block, or a damaged old block → one `agent-kit` block after a
  rerun, or exit 1 with nothing changed (Task 3 tests
  `test_old_and_new_blocks_collapse_to_one`, damaged-marker parameters).
