# Kit map Implementation Plan

- **Status:** approved
- **Date:** 2026-10-13

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a SessionStart hook that injects a short "kit map" (kit root plus absolute paths of the kit's playbooks and ADR folder) into every session, and replace the ad-hoc relative pointers that broke in child repos.

**Architecture:** One new hook, `plugin/hooks/kit_map_inject.py`, shaped like `lean_context_inject.py`: it finds the kit root from its own resolved path, parses the playbook table in `conventions/README.md`, and prints one SessionStart JSON object. The spec-gate skill passes the decision-log path to its reviewer subagent in the dispatch prompt, since subagents get no SessionStart output. Docs, an ADR and the manifest describe it.

**Tech Stack:** Python 3 (stdlib only), pytest, ruff; Markdown and JSON.

**Spec:** `docs/superpowers/specs/2026-10-13-kit-map-design.md`

## Context for the executor

This repo is claude-kit: a Claude Code plugin under `plugin/` plus workspace
conventions under `conventions/`. Hooks are Python scripts registered in
`plugin/hooks/hooks.json`; skills (`plugin/skills/<name>/SKILL.md`) are prompts
whose text tests check with string assertions. `tests/helpers.py` exports
`REPO` (repo root), `PLUGIN` (`REPO / "plugin"`), `clean_env(**extra)` (env
without `CLAUDE_KIT_*`) and `run_script(script, stdin=..., env=...)` (runs a
script with `sys.executable`, returns `CompletedProcess[str]`).

Before every commit run the full suite and lint from the repo root:

```bash
pytest -q
ruff check plugin tests
ruff format --check plugin tests
```

Every commit message ends with a blank line and
`Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Global Constraints

- Env switch: `CLAUDE_KIT_KIT_MAP=0` turns the hook off; any other value, or none, is on.
- The hook always exits 0; errors go to stderr as `[claude-kit] kit-map inject error: ...` (ADR 0007).
- `additionalContext` is at most 1,500 characters.
- Paths in the map use forward slashes (`Path.as_posix()`).
- Plugin version becomes `0.23.0`.
- The ADR is number 0032 and amends ADR 0027.
- No private repo names in tracked files.

## Review Focus

- A `conventions/README.md` row whose file does not exist: the row is skipped, not printed (Task 1 test `test_missing_playbook_file_is_skipped`).
- Rows outside `## The playbooks` that contain `.md` links: ignored (Task 1 test `test_only_playbooks_section_is_parsed`).
- Hook reached through the `~/.claude/skills/claude-kit` junction: the kit root is the real one (Task 1 test `test_resolves_through_link`).
- The link test's teardown must never delete through the junction into the real `plugin/` (Task 1 test fixture removes only the link).
- A plugin-only install (no `conventions/README.md` above `plugin/`): silent, exit 0 (Task 1 test `test_missing_conventions_prints_nothing`).

```python
#!/usr/bin/env python3
"""SessionStart hook: inject the kit map unless it is switched off.

The workspace CLAUDE.md links to conventions/ and knowledge/ relative to the
kit root, which breaks in child repos. This prints the kit root and the
absolute path of each playbook (from the table under ``## The playbooks`` in
conventions/README.md) and of the kit's ADR folder, so Claude can read them
from any repo (ADR 0032). On by default; CLAUDE_KIT_KIT_MAP=0 turns it off.
Prints nothing when the kit root has no conventions/README.md (a plugin-only
install). Always exits 0 (ADR 0007).
"""

from __future__ import annotations

import json
import os
import re
import sys
from pathlib import Path

ROW_RE = re.compile(r"^\|\s*\[([^\]]+)\]\(([^)#\s]+\.md)\)\s*\|")
SECTION = "## The playbooks"


def enabled() -> bool:
    return os.environ.get("CLAUDE_KIT_KIT_MAP") != "0"


def kit_root() -> Path | None:
    """The kit checkout: the parent of the real plugin/ folder, links followed."""
    root = Path(__file__).resolve().parents[2]
    return root if (root / "conventions" / "README.md").is_file() else None


def playbooks(root: Path) -> list[tuple[str, Path]]:
    """(link text, path) for each playbook row whose file exists."""
    conventions = root / "conventions"
    found: list[tuple[str, Path]] = []
    in_section = False
    for line in (conventions / "README.md").read_text(encoding="utf-8").splitlines():
        if line.startswith("## "):
            in_section = line.strip() == SECTION
            continue
        match = ROW_RE.match(line.strip())
        if in_section and match and (conventions / match.group(2)).is_file():
            found.append((match.group(1), conventions / match.group(2)))
    return found


def build_map(root: Path) -> str:
    lines = [
        f"Kit map (claude-kit). Kit root: {root.as_posix()}. Relative links in "
        "the workspace CLAUDE.md (e.g. conventions/, knowledge/, plugin/) "
        "resolve against the kit root, not the current repo."
    ]
    books = playbooks(root)
    if books:
        lines.append("Playbooks (read the one a task needs):")
        lines += [f"- {name}: {path.as_posix()}" for name, path in books]
    adrs = root / "knowledge" / "decisions"
    if adrs.is_dir():
        lines.append(f"Kit ADRs: {adrs.as_posix()}/")
    return "\n".join(lines)


def main() -> int:
    try:
        root = kit_root() if enabled() else None
        if root is not None:
            output = {
                "hookSpecificOutput": {
                    "hookEventName": "SessionStart",
                    "additionalContext": build_map(root),
                }
            }
            print(json.dumps(output))
    except Exception as exc:  # a hook must never raise
        print(f"[claude-kit] kit-map inject error: {exc}", file=sys.stderr)
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

```markdown
# ADR 0032: Kit map injected at session start

- **Status:** accepted
- **Date:** 2026-10-13

## Context
The workspace `CLAUDE.md` links to `conventions/` and `knowledge/decisions/`
relative to the kit root. Claude Code loads that file in a child repo, but
there those paths name folders inside the child, which do not exist. The
playbooks that define how we work were not reliably reachable from the repos
they govern; the spec-gate rubric and the lean-context rule patched this ad hoc.

## Decision
- A SessionStart hook (`kit_map_inject.py`, no matcher) injects a short kit
  map: the kit root, the rule that the workspace `CLAUDE.md`'s relative links
  resolve against it, the absolute path of each playbook (parsed from the
  table in `conventions/README.md`) and of the kit's ADR folder. Playbooks are
  read on demand.
- On by default; `CLAUDE_KIT_KIT_MAP=0` switches it off. With no
  `conventions/README.md` above `plugin/` it prints nothing.
- The spec-gate reviewer gets no session-start output, so the main session
  passes the decision-log path in the dispatch prompt, in place of the
  one-level-up fallback. This amends ADR 0027.
- No Read allow rule is added to user settings; an occasional permission
  prompt when Claude opens a kit file from a child repo is accepted.

## Alternatives
- `@` imports of the playbooks: about 8k tokens every session, and still
  tied to the folder layout.
- Copying the playbooks into child repos at scaffold time: drifts, and
  misses repos that never adopted the kit.

## Consequences
- One more always-on SessionStart injection of about 250 to 400 tokens.
- With the map switched off, the lean-context pointer names the
  session-hygiene playbook without a path; that is accepted.
```
