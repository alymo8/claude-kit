# Personal vault Implementation Plan

- **Status:** draft
- **Date:** 2026-11-10

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a personal-vault template, `/vault-init`, a `vault-pending.py` change detector, the `ingest` and `task-prompt` skills and a SessionStart hook that points every session at the vault when `CLAUDE_KIT_VAULT` is set.

**Architecture:** The template lives in `plugin/templates/vault/` and is copied by a standard-library script, `plugin/scripts/vault-init.py`, which writes `vault.toml` and `.gitignore` per profile and makes one git commit. `plugin/scripts/vault-pending.py` compares `raw/` files with the `raw`/`sha256` frontmatter of `wiki/sources/*.md` and also extracts `.docx` text. Two Markdown skills drive the LLM work; a new hook, `plugin/hooks/vault_inject.py`, injects one line. Docs, ADR 0040 and a minor version bump (0.27.1 to 0.28.0) finish the change.

**Tech Stack:** Python 3.11+ standard library (`tomllib`, `zipfile`, `xml.etree`, `hashlib`), pytest, ruff, Markdown, JSON, git.

**Spec:** `docs/superpowers/specs/2026-11-10-vault-design.md`

Spec gate record: `docs/superpowers/gates/2026-11-10-vault-design.md`

## Decisions already made (do not relitigate)

All of the spec's Decisions section: tooling in the kit and content in each
vault; one vault per machine with `personal`/`work` profiles that change only
defaults; one generic `topics/` registry with a free-text `kind`; Obsidian is

### Plan-level answers to the spec gate's plan questions

- **Git identity for the scaffold commit:** `vault-init.py` reuses
  `scaffold.py`'s rule: if `git config --get user.name` or `user.email` fails
  in the new vault, the commit runs with
  `-c user.name=claude-kit -c user.email=claude-kit@localhost`; it never writes
  git config. A test runs it with an empty global config. (Task 1)
- **`raw/` walk and vanished raw files:** the walk is recursive
  (`raw/web/2026/x.md` counts) and skips any path with a component starting
  with `.`. A source page whose `raw` file no longer exists is reported with
  status `missing` (text line `missing\t<raw path>`, JSON `source` = the
  page). The ingest skill lists `missing` entries in its report and leaves
  those pages unchanged; the user decides. (Task 2, Task 4)
- **Task file date and topic:** a task file is named
  `<call date>-<slug of the action item>.md`, the call date being the source
  page's `date` (the ingest date only when the call states no date). `topic`
  is the one topic the action item is about; when it is not clear, the first
  entry of the call's source-page `topics` list; empty when the call has
  none. (Task 4)

### Other plan-level choices

- The template folder holds no `vault.toml` or `.gitignore`; `vault-init.py`
  writes both, so profile values live in one place (`PROFILES` in the
  script).
- `person.md` and `topic.md` carry `aliases: []` (Obsidian's alias
  property), which is what ingest searches besides the page name.
- Wiki-links in frontmatter are quoted (`source: "[[2026-11-03-atlas-sync]]"`)
  so Obsidian parses them; `vault-pending.py`'s parser strips one pair of
  surrounding quotes.
- `--extract` prints one line per non-empty paragraph.

def make_vault(root: Path) -> Path:
    (root / "raw").mkdir(parents=True)
    (root / "wiki" / "sources").mkdir(parents=True)
    (root / "vault.toml").write_text('profile = "personal"\n', encoding="utf-8")
    return root


def raw(vault: Path, rel: str, data: bytes = b"hello") -> str:
    path = vault / rel
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_bytes(data)
    return hashlib.sha256(data).hexdigest()


def source(vault: Path, name: str, rel: str, sha: str, nl: str = "\n",
           bom: bool = False) -> None:
    text = nl.join(["---", "type: source", f"raw: {rel}", f"sha256: {sha}",
                    "---", "## Summary", ""])
    data = ("﻿" if bom else "") + text
    (vault / "wiki" / "sources" / name).write_bytes(data.encode("utf-8"))


def run(vault: Path, *args: str):
    return run_script(SCRIPT, str(vault), *args)

    v = make_vault(tmp_path)
    raw(v, "raw/web/a-new.md")
    old = raw(v, "raw/docs/b-changed.md", b"v1")
    raw(v, "raw/docs/b-changed.md", b"v2")
    source(v, "2026-11-01-b.md", "raw/docs/b-changed.md", old)
    same = raw(v, "raw/notes/c-same.txt")
    source(v, "2026-11-01-c.md", "raw/notes/c-same.txt", same)
    source(v, "2026-11-01-d.md", "raw/web/d-gone.md", same)
