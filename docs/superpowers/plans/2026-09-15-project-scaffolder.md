# Project Scaffolder and Spec Lifecycle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

- **Status:** approved
- **Date:** 2026-09-15

**Goal:** Add `/new-project` and `/adopt-conventions` commands (a template tree + `scaffold.py`) so any repo gets the kit's conventions in one step, and a spec lifecycle (`draft | approved | implemented | superseded`) with a generated per-repo index.

**Architecture:** `plugin/templates/project/` holds the files a project receives; `plugin/templates/stacks/{node,python}/` holds the stack-specific `ci.yml` and two `.part` snippets spliced into `CLAUDE.md` and `.gitignore`. `plugin/scripts/scaffold.py` renders them with `str.replace` on `{{name}}` placeholders, either into a new git-initialised project or (adopt mode) into an existing repo, writing only missing files. `plugin/scripts/spec-index.py` regenerates `docs/superpowers/README.md`; the existing `on_spec_edit.py` hook calls it after rendering. Everything is tested with pytest against `tmp_path`.

**Tech Stack:** Python 3.11+ (3.13 locally), pytest, ruff `~=0.16`, git ≥ 2.28, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-15-project-scaffolder-design.md` — read it first; the plan implements it section by section.

## Why this exists (for an executor with no context)

The kit's five conventions are adopted by 4 of ~30 project repos because adoption means hand-creating ~15 files. Specs also have no lifecycle beyond `draft | approved` and no index, so nobody can tell which specs are live. This plan makes adoption one command and makes the index generate itself.

## Decisions already made (do not relitigate)

- Template tree + Python script (not a prompt-only command, not cookiecutter).
- New mode does `git init -b main` + one commit; it never creates the GitHub repo.
- Adopt mode never overwrites or merges; `.gitignore` is reported, not merged.
- Minimal knowledge layer (index + decisions + archive); no domain folders.
- The index is regenerated by the existing hook, not on demand.
- Project CI templates are ubuntu-only; the AI-review workflow ships as `workflow_dispatch` only.
- The scaffolder does not create `package.json` / `pyproject.toml`.

## Global Constraints

- Repo root: `<repo-root>` (the `Desktop/Github` checkout; remote `alymo8/claude-kit`, **public**). Never write private repo names or the Windows username into tracked files, templates included; refer to other repos as "a project repo".
- `.gitignore` is a whitelist. `plugin/` is already whitelisted, so `plugin/templates/` and `plugin/commands/` are tracked automatically — but `.gitkeep` files and `.github/` inside `plugin/templates/project/` must not be ignored by any pattern: verify with `git status` that every template file shows up.
- Placeholder syntax is exactly `{{identifier}}` — lowercase letters and underscores, no spaces. GitHub Actions expressions `${{ secrets.X }}` contain a space after `{{` and are therefore not placeholders; the validator regex is `\{\{[a-z_]+\}\}`.
- Rendered HTML (`docs/superpowers/**/*.html`) is never committed.
- `ruff format plugin tests && ruff check plugin tests` before every commit; run the full suite (`python -m pytest tests -q`) once before each commit. Lines ≤ 88 chars.
- Hook scripts always exit 0; `spec-index.py` always exits 0.
- Commit messages: imperative subject; end with the two attribution lines the session provides.

`plugin/scripts/spec-index.py`:

```python
#!/usr/bin/env python3
"""Regenerate docs/superpowers/README.md: an index of a repo's specs and plans.

    python spec-index.py [DOCS_DIR]      # DOCS_DIR defaults to ./docs/superpowers

Each spec/plan row shows its date, title (linked) and Status. Title is the first
``# `` heading (fallback: file stem); Status comes from a ``**Status:**`` line
(fallback: an em dash); Date from a ``**Date:**`` line, else the filename's
``YYYY-MM-DD-`` prefix. Nothing is written when the content is unchanged, and
nothing at all when neither specs/ nor plans/ exists. Always exits 0.
"""

from __future__ import annotations

import re
import sys
from pathlib import Path

HEADER = (
    "# Specs and plans\n\n"
    "<!-- generated by claude-kit spec-index.py; do not edit by hand -->\n"
)
TITLE_RE = re.compile(r"^# (.+?)\s*$", re.M)
STATUS_RE = re.compile(r"\*\*Status:\*\*\s*([a-z]+)")
DATE_RE = re.compile(r"\*\*Date:\*\*\s*(\d{4}-\d{2}-\d{2})")
FILE_DATE_RE = re.compile(r"^(\d{4}-\d{2}-\d{2})-")
MISSING = "—"


def entry(md: Path) -> tuple[str, str, str]:
    """Return (date, title, status) for one spec or plan."""
    text = md.read_text(encoding="utf-8")
    title_match = TITLE_RE.search(text)
    title = title_match.group(1) if title_match else md.stem
    status_match = STATUS_RE.search(text)
    status = status_match.group(1) if status_match else MISSING
    date_match = DATE_RE.search(text) or FILE_DATE_RE.search(md.name)
    date = date_match.group(1) if date_match else MISSING
    return date, title.replace("|", "\\|"), status


def section(label: str, folder: Path, docs_dir: Path) -> str:
    lines = [f"## {label}s", "", f"| Date | {label} | Status |", "|---|---|---|"]
    if folder.is_dir():
        rows = []
        for md in folder.glob("*.md"):
            date, title, status = entry(md)
            rel = md.relative_to(docs_dir).as_posix()
            rows.append((date, md.name, f"| {date} | [{title}]({rel}) | {status} |"))
        rows.sort(key=lambda r: r[1])
        rows.sort(key=lambda r: r[0], reverse=True)
        lines.extend(row for _, _, row in rows)
    return "\n".join(lines) + "\n"


def render(docs_dir: Path) -> str:
    specs = section("Spec", docs_dir / "specs", docs_dir)
    plans = section("Plan", docs_dir / "plans", docs_dir)
    return HEADER + "\n" + specs + "\n" + plans


def write_index(docs_dir: Path) -> Path | None:
    if not (docs_dir / "specs").is_dir() and not (docs_dir / "plans").is_dir():
        return None
    out = docs_dir / "README.md"
    text = render(docs_dir)
    if out.exists() and out.read_text(encoding="utf-8") == text:
        return out
    out.write_text(text, encoding="utf-8")
    return out


def main(argv: list[str]) -> int:
    docs_dir = Path(argv[0]) if argv else Path.cwd() / "docs" / "superpowers"
    try:
        write_index(docs_dir)
    except Exception as exc:  # never block a hook
        print(f"[claude-kit] spec-index error: {exc}", file=sys.stderr)
    return 0


if __name__ == "__main__":
    raise SystemExit(main(sys.argv[1:]))
```

```python
import re
from collections.abc import Iterable

LINK_RE = re.compile(r"\]\(([^)\s]+)\)")
FENCE_RE = re.compile(r"^```.*?^```[ \t]*$", re.M | re.S)


def broken_links(md_files: Iterable[Path]) -> list[str]:
    """Relative markdown links (outside code fences) that do not resolve."""
    broken = []
    for md in md_files:
        prose = FENCE_RE.sub("", md.read_text(encoding="utf-8"))
        for match in LINK_RE.finditer(prose):
            href = match.group(1).split("#", 1)[0]
            if not href or "://" in href or href.startswith("mailto:"):
                continue
            if not (md.parent / href).exists():
                broken.append(f"{md} -> {href}")
    return broken
```

`plugin/scripts/scaffold.py`:

```python
#!/usr/bin/env python3
"""Scaffold a project from the kit's templates, or add the missing files to one.

    scaffold.py --name NAME --stack {node,python} [--parent DIR]
    scaffold.py --adopt --stack {node,python} [--dest DIR] [--name NAME]

New mode renders plugin/templates/ into PARENT/NAME (PARENT defaults to the
directory the kit checkout lives in), then runs `git init -b main` and one commit.
It refuses a non-empty destination. Adopt mode writes only the files that do not
already exist in DEST (default: the current directory, which must be a git work
tree) and never commits. Neither mode creates a GitHub repository or a stack
manifest (package.json / pyproject.toml): run the framework's own init for that.

Exit codes: 0 success; 1 refusal (message on stderr); 2 usage.
"""

from __future__ import annotations

import argparse
import datetime as dt
import re
import subprocess
import sys
from pathlib import Path

PLUGIN_ROOT = Path(__file__).resolve().parent.parent
TEMPLATES = PLUGIN_ROOT / "templates"
INDEXER = PLUGIN_ROOT / "scripts" / "spec-index.py"
STACKS = ("node", "python")
PLACEHOLDER_RE = re.compile(r"\{\{[a-z_]+\}\}")
CI_PATH = Path(".github/workflows/ci.yml")
NEXT_STEPS = {
    "node": "next: `pnpm init` (or a framework starter), then commit package.json",
    "python": (
        "next: `uv init` and `uv add --dev pytest ruff`, then commit pyproject.toml"
    ),
}


def render_files(name: str, stack: str, today: str) -> dict[Path, str]:
    """Render every template file for one stack. Keys are project-relative paths."""
    stack_dir = TEMPLATES / "stacks" / stack
    values = {
        "project_name": name,
        "date": today,
        "stack": stack,
        "stack_commands": (stack_dir / "commands.part").read_text("utf-8").rstrip("\n"),
        "stack_gitignore": (stack_dir / "gitignore.part").read_text("utf-8").rstrip("\n"),
    }
    root = TEMPLATES / "project"
    files: dict[Path, str] = {}
    for src in sorted(p for p in root.rglob("*") if p.is_file()):
        rel = src.relative_to(root)
        source = stack_dir / "ci.yml" if rel == CI_PATH else src
        text = source.read_text(encoding="utf-8")
        for key, value in values.items():
            text = text.replace("{{" + key + "}}", value)
        leftover = PLACEHOLDER_RE.search(text)
        if leftover:
            raise ValueError(f"unresolved placeholder {leftover.group(0)} in {rel}")
        files[rel] = text
    return files


def write_files(dest: Path, files: dict[Path, str]) -> None:
    for rel, text in files.items():
        path = dest / rel
        path.parent.mkdir(parents=True, exist_ok=True)
        path.write_text(text, encoding="utf-8")


def git(*args: str, cwd: Path) -> subprocess.CompletedProcess[str]:
    return subprocess.run(
        ["git", *args], cwd=cwd, capture_output=True, text=True, encoding="utf-8"
    )


def commit_all(dest: Path, message: str) -> None:
    identity: list[str] = []
    if git("config", "--get", "user.name", cwd=dest).returncode != 0:
        identity = ["-c", "user.name=claude-kit", "-c", "user.email=claude-kit@localhost"]
    for args in (["init", "-q", "-b", "main"], ["add", "-A"],
                 [*identity, "commit", "-q", "-m", message]):
        result = git(*args, cwd=dest)
        if result.returncode != 0:
            raise SystemExit(f"error: git {args[0]} failed: {result.stderr.strip()}")


def scaffold_new(name: str, stack: str, parent: Path) -> Path:
    dest = parent / name
    if dest.exists() and any(dest.iterdir()):
        raise SystemExit(f"error: {dest} already exists and is not empty")
    files = render_files(name, stack, dt.date.today().isoformat())
    write_files(dest, files)
    commit_all(dest, "Scaffold project from claude-kit")
    print(f"created: {len(files)} files at {dest}")
    for rel in files:
        print(f"  {rel.as_posix()}")
    print()
    print(NEXT_STEPS[stack])
    print("then: /init to fill in CLAUDE.md; create the remote when ready "
          "(e.g. `gh repo create --private`).")
    return dest


def build_parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(description=__doc__.splitlines()[0])
    parser.add_argument("--name", help="project name (new mode: also the folder name)")
    parser.add_argument("--stack", choices=STACKS, required=True)
    parser.add_argument("--parent", type=Path, default=PLUGIN_ROOT.parent.parent,
                        help="new mode: directory to create the project in")
    parser.add_argument("--adopt", action="store_true",
                        help="add missing files to an existing repo instead")
    parser.add_argument("--dest", type=Path, default=Path.cwd(),
                        help="adopt mode: the repo to add files to (default: cwd)")
    return parser


def main(argv: list[str]) -> int:
    args = build_parser().parse_args(argv)
    if args.adopt:
        raise SystemExit("error: adopt mode is not implemented yet")
    if not args.name:
        build_parser().error("--name is required in new mode")
    scaffold_new(args.name, args.stack, args.parent)
    return 0


if __name__ == "__main__":
    raise SystemExit(main(sys.argv[1:]))
```

Note `PLUGIN_ROOT.parent.parent`: the script is at `<kit>/plugin/scripts/scaffold.py`, so `PLUGIN_ROOT` is `<kit>/plugin` and `.parent.parent` is the directory containing the kit checkout — the workspace root. Through the junction, `resolve()` follows to the real checkout, so this still holds.

```python
def inside_git_work_tree(path: Path) -> bool:
    return git("rev-parse", "--is-inside-work-tree", cwd=path).returncode == 0


def scaffold_adopt(name: str, stack: str, dest: Path) -> tuple[list[Path], list[Path]]:
    if not dest.is_dir() or not inside_git_work_tree(dest):
        raise SystemExit(f"error: {dest} is not inside a git work tree")
    files = render_files(name, stack, dt.date.today().isoformat())
    created: list[Path] = []
    skipped: list[Path] = []
    for rel, text in files.items():
        path = dest / rel
        keep_in_populated_dir = rel.name == ".gitkeep" and path.parent.is_dir() and any(
            path.parent.iterdir()
        )
        if path.exists() or keep_in_populated_dir:
            skipped.append(rel)
            continue
        path.parent.mkdir(parents=True, exist_ok=True)
        path.write_text(text, encoding="utf-8")
        created.append(rel)
    # The template index is empty; regenerate it from whatever specs/plans exist.
    subprocess.run(
        [sys.executable, str(INDEXER), str(dest / "docs" / "superpowers")],
        capture_output=True,
        text=True,
        encoding="utf-8",
        timeout=30,
    )
    print("created:")
    for rel in created:
        print(f"  {rel.as_posix()}")
    print("skipped (already present):")
    for rel in skipped:
        print(f"  {rel.as_posix()}")
    if Path(".gitignore") in skipped:
        print("check .gitignore contains: docs/superpowers/**/*.html and .env*")
    print("review with `git status`, then commit.")
    return created, skipped
```
